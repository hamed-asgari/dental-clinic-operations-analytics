# Project Charter

## Project title
Dental Clinic Operations Analytics

## Background
The project owner is a general dentist developing skills in clinical data science and artificial intelligence. The first portfolio project should connect existing knowledge of dentistry, SQL, Python, pandas, machine learning, and Power BI.

## Primary user
A dental-clinic manager who wants to understand operational performance and identify practical improvements.

## Core question
How can appointment, procedure, treatment-plan, and payment data be transformed into clear operational decisions for a dental clinic?

## Scope - version 1.0
1. Synthetic patient and appointment data.
2. Relational database design.
3. SQL analysis.
4. Python exploratory analysis.
5. Power BI dashboard.
6. Short management report in English.

## Out of scope - version 1.0
- Real patient data.
- Clinical diagnosis or treatment recommendations.
- Machine-learning prediction.
- Cloud deployment.
- A production-grade clinic management system.

## Deliverables
- Reproducible data-generation script.
- SQL schema and analytical queries.
- EDA notebook.
- Power BI dashboard file and screenshots.
- README and management summary.

## Success criteria
- A new user can reproduce the synthetic data.
- Primary and foreign-key relationships are valid.
- At least ten useful SQL queries are documented.
- Dashboard KPIs answer practical management questions.
- The project can be explained in five minutes in English.

## Constraints
- Maximum completion time: four weeks.
- Weekly project time: 8-12 focused hours.
- No personally identifiable or real clinical data.
